Project Title
Predicting SLA Breaches and Ticket Resolution Delays in Jira Service Management

Project Overview
This project investigates how historical Jira Service Management data can be used to identify patterns associated with ticket delays and SLA breaches.

The project is based on a real business challenge observed in my professional environment. Jira Service Management is used daily to manage incidents, service requests and technical support activities. One recurring issue is that many tickets remain open longer than expected due to missing information, delayed user responses or high workloads within support queues.

The objective is to explore whether data analytics and machine learning techniques can help identify tickets at risk of SLA breaches and support proactive decision-making.
